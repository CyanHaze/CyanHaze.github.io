# Windows Shortcut Key

### 基本快捷键

- **Ctrl + C**：复制选中的内容
- **Ctrl + V**：粘贴复制的内容
- **Ctrl + X**：剪切选中的内容
- **Ctrl + Z**：撤销上一步操作
- **Ctrl + Y**：重做上一步操作
- **Ctrl + A**：全选
- **Ctrl + F**：打开搜索栏
- **Ctrl + S**：保存当前文件
- **Ctrl + P**：打印当前文件

### 文件管理

- **Windows + E**：打开文件资源管理器
- **Alt + F4**：关闭当前窗口
- **F2**：重命名选中的文件或文件夹
- **Delete**：删除选中的文件或文件夹
- **Shift + Delete**：永久删除选中的文件或文件夹

### 系统操作

- **Windows + D**：显示桌面
- **Windows + L**：锁定计算机
- **Windows + R**：打开“运行”对话框
- **Windows + I**：打开设置
- **Windows + X**：打开快速链接菜单（包含设备管理器、任务管理器等）
- **Windows + Tab**：打开任务视图

### 多任务处理

- **Alt + Tab**：切换应用程序
- **Ctrl + Shift + Esc**：打开任务管理器
- **Windows + Number (1-9)**：打开任务栏上对应位置的应用程序

### 浏览器快捷键

- **Ctrl + T**：打开新标签页
- **Ctrl + W**：关闭当前标签页
- **Ctrl + Shift + T**：重新打开最后关闭的标签页
- **Ctrl + L**：选中地址栏
- **F5**：刷新页面
- **Ctrl + R**：重新加载页面

### 其他常用快捷键

- **Windows + M**：最小化所有窗口
- **Windows + Shift + M**：恢复最小化的窗口
- **Windows + S**：打开搜索
- **Windows + P**：选择投影模式（仅适用于连接外部显示器）
