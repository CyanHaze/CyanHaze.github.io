Method

Numerical demonstrations

We give a multimodal model one robot trajectory as context and use its predictions to control the hands. The model runs without task-specific fine-tuning.

Each trajectory contains timestamps, 52-dimensional measured states, and 52-dimensional action commands. The state records both palms’ positions and rotations, together with 40 finger joint angles.

During execution, the model receives the task instruction, three RGB views, measured robot state, and execution feedback. It predicts palm and finger targets, then observes the result before issuing the next command.

Protocol

Experimental setup

Each task uses one official training episode, retaining all frames and the original timestamps. Every trial has a budget of 100 model requests, with up to 4,096 output tokens per request.

Task / reference episodeReference framesControl-step budget
T10Lift a carton / 6103244864
T18Open a micropipette box / 1417525375
T19Set a cup upright / 150367222

HandsOn runs at 30 Hz with the native controller. T10 scoring uses bimanual support, lift, and hold; contact force is recorded for diagnostics.

Experiments use HandsOn official demonstrations and simulation environment.
